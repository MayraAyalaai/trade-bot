# Crypto Trading Bot

A simple cryptocurrency trading bot for automated trading strategies.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Copy `.env.example` to `.env` and configure your API keys:
```bash
cp .env.example .env
```

3. Run the bot:
```bash
npm start
```
